# 🧮 Projeto Calculadora - Desafio da Mentoria de Júlio de Lima

Este projeto foi desenvolvido como parte de um **desafio prático da Mentoria de Qualidade de Software do Júlio de Lima**.  
O objetivo é criar uma **calculadora simples em JavaScript** e implementar **testes automatizados** usando o framework [Mocha](https://mochajs.org/) e a biblioteca [Chai](https://www.chaijs.com/).


## Estrutura do Projeto

```plaintext
📦 logica-e-programacao
 ┣ 📂 src
 ┃ ┗ calculadora.js        # Funções da calculadora
 ┣ 📂 test
 ┃ ┗ calculadora.test.js   # Testes automatizados com Mocha + Chai
 ┣ 📜 .gitignore
 ┣ 📜 package.json
 ┣ 📜 package.lock.json
 ┗ 📜 README.md
```

## Funcionalidades Implementadas

- **Somar dois números** (positivos, negativos, zero)
- **Subtrair dois números** (positivos, negativos)
- **Multiplicar dois números** (positivos, negativos, por zero)
- **Dividir dois números** (positivos, negativos, zero)
- **Calcular a média de dois números**


##  Tecnologias Utilizadas

- **JavaScript (Node.js)**
- **Mocha** – Framework de testes
- **Chai** – Biblioteca de asserções
